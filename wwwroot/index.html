    Drivers

    Checks Windows Update, the Microsoft Update Catalog, NVIDIA, AMD, Intel and winget, and only offers drivers Windows would pick for your exact hardware. A restore point and a backup are made before anything changes.

    Apps

    Updates for the programs on this PC, from winget. Installers come from each publisher's own download and are checked against the catalog's hash before they run. New programs are picked up as soon as you install them.

    Security

    Microsoft Defender does the virus scanning. SystemForge adds its own checks for adware, browser hijacks, hidden auto-start tricks, scam remote sessions and weakened settings. Fixes move things to quarantine or switch them off, and every change can be undone.

    Security checks inspired by , used with his permission.

    Cleanup

    Removes leftovers from a fixed list of places. Anything in use is skipped, and your documents, saves and logins are never touched.

    Startup

    Apps that open when you sign in. Turning one off doesn't uninstall it, and you can turn it back on any time.

    About & credits

    SystemForge is a PC-care app for Windows: drivers, app updates, security checks, cleanup, startup and performance.

    The Security page's checks and its safety rules (quarantine instead of delete, an undo history, never touching Windows' own files) are inspired by , an open-source PC health and adware scanner, and are used with his permission.

    Temperatures and fan speeds are read with LibreHardwareMonitor (Mozilla Public License 2.0). CPU and motherboard sensors use the optional PawnIO driver by namazso.

    Virus scanning is done by Microsoft Defender. Drivers come from Windows Update, the Microsoft Update Catalog, NVIDIA, AMD and Intel; apps and game components from winget.
